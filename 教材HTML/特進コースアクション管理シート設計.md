# 特進コース アクション管理シート 設計書

---

## 全体構想（システム全体像）

### 関係者と権限

| 役割 | 人数 | 閲覧範囲 | 操作 |
|------|------|----------|------|
| 統括（管理者） | 1名 | 全生徒・全チームのデータ | ダッシュボード閲覧・管理 |
| リーダー（チームリーダー） | 5名（5チーム） | 自チームの生徒データ | チーム実績の確認 |
| コーチング担当者 | 約60名 | 担当生徒 + 全生徒（閲覧可） | 目標設定・実績入力・振り返り確認 |
| 生徒 | 多数 | 自分のデータのみ | 目標確認・自己評価・実績入力 |

### 現状の課題

- スプレッドシートを使えないコーチング担当者が多い（60名中かなりの割合）
- 生徒もスプレッドシート操作が苦手、スマホ完結が理想
- 現行のテンプレ複製方式は使いにくい
- データ入力が重複している（投稿数の取得など）
- 入力の手間が多い

### 9ブロックの構成（確定版）

> 7つの30日期間を、9つのブロックで管理する。
> 31〜60日と91〜120日は同じ月の中に「プログラム完了」「通常運用」の2サブブロックを持つ。

| Block | 経過日数 | サブ | 投稿目安 | 記入日→結果日 | 主なアクション |
|-------|---------|------|---------|-------------|--------------|
| 1 | 0〜30日 | - | 0投稿 | 3/1→4/1 | スタータープログラム完了(10日) / アカウント設計完了(13日) / クラスHR / 目標設定セッション / 1回目通常セッション / 講師1on1 |
| 2 | 31〜60日 | 完了系 | ※(1) | 4/1→5/1 | 投稿スタータープログラム完了 |
| 3 | 31〜60日 | 運用系 | 15投稿 | 4/1→5/1 | 投稿スターター完了(27日) / 2-3回目通常セッション / 1-2回目添削会 |
| 4 | 61〜90日 | - | 18投稿 | 5/1→6/1 | 4-5回目通常セッション / 3-4回目添削会 |
| 5 | 91〜120日 | 完了系 | ※(20) | 6/1→7/1 | スタータープログラム完了 |
| 6 | 91〜120日 | 運用系 | 20投稿 | 6/1→7/1 | 6-7回目通常セッション / 5-6回目添削会 |
| 7 | 121〜150日 | - | 20投稿 | 7/1→8/1 | 8-9回目通常セッション / 7-8回目添削会 |

| 9 | 181〜210日 | - | 10投稿 | 9/1→10/1 | 12回目通常セッション |

> **投稿目安 合計: 0+15+18+20+20+17+10 = 100投稿**
> ※ Block2の(1)とBlock5の(20)は開始時点の累計投稿数の参考値

### 全ブロックの振り返り項目

全9ブロックに以下を配置:
- 投稿評価 / 成長評価 / 総合評価（各10点満点）
- グッド×3 + バッド×3（理由・原因・改善策つき）
- メモ / 今月の総評 / 来月の目標 / **ビジョンに対する現状**

### シート利用ルール（テンプレートに記載済み）

1. 投稿目標数は**半角数字のみ**（単位は書かない）
2. 行の追加時は関数入りセルに注意
3. 日付入力は `command + :` を使用
4. 投稿は講師の添削付きのみカウント。1日2投稿しても1回カウント
5. 薄いグレーのセルは変更不可
6. 目標設定セッション ＝ 初回セッション

### 目標達成シート導入の目的

1. チェックポイントを細かく設定 → 中弛み防止
2. 進捗の監視
3. ゴールとビジョンの明確化 → 月1回ビジョン振り返り
4. 数値で把握 → 行動基準の明確化
5. 大目標からの逆算意識
