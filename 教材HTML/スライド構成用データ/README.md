# スライド構成用データ

このディレクトリには、NotebookLMでスライドを作成するためのテンプレートとプロンプトが格納されています。

## ファイル構成

- `ダイエットサポート資料のコピー　（営業資料作成元として）++.pdf`
  - 元となるデザイン資料（82ページ）
  - このPDFを分析して、YAMLプロンプトテンプレートを作成しました

- `notebooklm_yaml_prompt.md`
  - NotebookLM用のYAMLプロンプトテンプレート（詳細版）
  - スライドタイプの定義と使用例を含む
  - 新しい資料を作成する際の参考として使用

- `notebooklm_yaml_prompt_sales.md`
  - NotebookLM用のYAMLプロンプトテンプレート（営業資料版・20ページ程度）
  - 営業資料に適した構成（約15-20スライド）
  - よりシンプルで実用的なテンプレート

- `notebooklm_prompt_template.txt`
  - CursorやClaudeで使用する際のプロンプト例
  - PDFから直接YAMLを生成する方法
  - テンプレートを使って新規資料を作成する方法

- `extract_pdf_structure.py`
  - PDFの構造を分析するためのPythonスクリプト
  - pdfplumberを使用してPDFからテキストを抽出

## 使い方

### パターン1: 営業資料（20ページ程度）を作成したい場合

1. Cursorでこのディレクトリを開く
2. `notebooklm_yaml_prompt_sales.md` を参照
3. 以下のようなプロンプトを送信：

```
以下の内容で営業資料（20ページ程度）を作成してください。
添付されている「notebooklm_yaml_prompt_sales.md」のテンプレート構造をもとに、
以下の内容を反映したNotebookLM用のYAML形式のスライド指定を生成してください。

【作成したい営業資料の内容】
[資料の内容を記述]

【参考テンプレート】
notebooklm_yaml_prompt_sales.md のスライドパターンを使用
約15-20ページ程度の構成にする
```

### パターン1-2: 詳細な資料を作成したい場合

1. Cursorでこのディレクトリを開く
2. `notebooklm_yaml_prompt.md` を参照
3. 以下のようなプロンプトを送信：

```
以下の内容でスライド資料を作成してください。
添付されている「notebooklm_yaml_prompt.md」のテンプレート構造をもとに、
以下の内容を反映したNotebookLM用のYAML形式のスライド指定を生成してください。

【作成したい資料の内容】
[資料の内容を記述]

【参考テンプレート】
notebooklm_yaml_prompt.md のスライドパターンを使用
```

### パターン2: 別のPDFから新しいYAMLプロンプトを作成したい場合

1. 新しいPDFをこのディレクトリに配置
2. 以下のプロンプトを送信：

```
添付されているPDF資料を分析して、
NotebookLMでスライドを作成する際に使用するYAML形式のプロンプトを作成してください。
「notebooklm_yaml_prompt.md」の形式を参考にしてください。

【要件】
1. PDFのスライド構造、レイアウト、デザインパターンを分析
2. 同様のスタイルで新しいスライドを作成する際に使えるYAMLテンプレートを作成
3. 各スライドタイプの定義と使用例を含める

【注意事項】
- パターンや背景の装飾的なアイコンは後から削除可能であることを考慮
- 実用的で汎用的なテンプレートとして設計
```

## 特徴

- **汎用的**: 他の資料にも転用可能なテンプレート構造
- **実用的**: すぐに使えるYAML形式のスライド指定
- **柔軟性**: 不要な装飾は後から削除可能
- **再利用性**: 同じテンプレートで複数の資料を作成可能

## 注意事項

- PDFの1ページ目にあるパターンや背景アイコンなどの装飾要素は、必要に応じて削除してください
- テンプレートは参考として使用し、内容に応じてカスタマイズしてください
- NotebookLMのYAML形式が変更された場合は、テンプレートも更新が必要です
