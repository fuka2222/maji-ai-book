# NotebookLMでスライド作成する際にYAML指定するプロンプト

## 基本プロンプト

以下のプロンプトをNotebookLMに送信すると、添付したPDF資料をもとにYAML形式のスライド指定を作成してくれます：

```
添付資料（PDF）を分析して、NotebookLMでスライドを作成する際に使用するYAML形式のプロンプトを作成してください。

【要件】
1. 添付資料のスライド構造、レイアウト、デザインパターンを分析
2. 同様のスタイルで新しいスライドを作成する際に使えるYAMLテンプレートを作成
3. 各スライドタイプの定義と使用例を含める

【出力形式】
- YAMLスキーマ定義
- 各スライドタイプの説明
- 実際の使用例
- デザイン指針

【注意事項】
- パターンや背景の装飾的なアイコンは後から削除可能であることを考慮
- 実用的で汎用的なテンプレートとして設計
- 他の資料にも転用できる形式にする
```

## 新しい資料作成時のプロンプト例

新しい資料を作成したい場合：

```
以下の内容でスライド資料を作成してください。添付されているYAMLテンプレート（notebooklm_yaml_prompt.md）の構造をもとに、以下の内容を反映したYAML形式のスライド指定を生成してください。

【作成したい資料の内容】
[ここに資料の内容や要件を記述]

【参考テンプレート】
notebooklm_yaml_prompt.md の構造とパターンを使用

【出力】
NotebookLMで使用できるYAML形式のスライド構成を出力してください。
```

## プロンプトの使い方

### パターン1: PDFから直接YAMLプロンプトを生成
1. PDFファイルを添付
2. 上記の「基本プロンプト」を送信
3. 生成されたYAMLプロンプトを保存

### パターン2: 既存のYAMLプロンプトテンプレートを使って新規資料作成
1. `notebooklm_yaml_prompt.md` を添付
2. 作成したい資料の内容を説明
3. テンプレートをもとにYAML形式のスライド構成を生成してもらう

### パターン3: 両方を使って最適化
1. PDFとYAMLプロンプトテンプレートの両方を添付
2. 「このPDFの構造を分析し、notebooklm_yaml_prompt.mdのテンプレートを参考にして、新しい資料用のYAMLプロンプトを作成してください」
3. 内容の説明を追加して、カスタマイズされたYAMLを生成
