# NotebookLM用スライド作成YAMLプロンプト

## 使い方

このプロンプトを使用して、NotebookLMでスライドを作成する際に、以下のYAML形式でスライド構成を指定してください。

## テンプレート構造

添付資料（ダイエットサポート資料）を分析した結果、以下のスライドパターンが確認できました：

### 基本的なスライド構成パターン

1. **タイトル・自己紹介スライド**
   - 講師名・肩書き
   - 実績や信頼性を示すポイント（箇条書き）

2. **カテゴリ・タイプ分類スライド**
   - タイプ番号＋名称（シンプルで大きく）

3. **特徴・課題説明スライド**
   - タイトル：カテゴリ名＋特徴と課題
   - 「こんな人が当てはまる」セクション
   - 「改善のカギ」セクション
   - 「なぜ○○なのか？」セクション
   - 問題点の視覚的な説明（図解風）

4. **改善プラン・提案スライド**
   - タイトル：カテゴリ名＋改善プラン名
   - 提案方針（メッセージ）
   - 1日の食事スケジュール（朝・昼・夜）
   - 各食事のポイント（たんぱく質目標など）

5. **実践例・メニュー例スライド**
   - タイトル：改善プラン名＋実践メニュー例
   - 具体的なメニュー例
   - 成功のコツ

6. **共感・問題提起スライド**
   - 質問形式のタイトル
   - 読者の経験に共感
   - 問題意識の喚起

7. **価値提案スライド**
   - 私たちが大切にしていること
   - 独自の価値やアプローチ
   - ゴール設定の考え方

8. **実績・成果スライド**
   - 数値で示す成果（平均・最大など）
   - 注目すべきポイント
   - 成果が出た理由

9. **参加者の声スライド**
   - タイトル：「参加者からの嬉しいお声」
   - なぜ継続できたか
   - 具体的な声

10. **CTA・問い合わせスライド**
    - 行動喚起

## NotebookLM用YAML指定例

```yaml
slides:
  - type: title_intro
    title: "[講師名・肩書き]"
    content:
      - bullet: "[実績ポイント1]"
      - bullet: "[実績ポイント2]"
      - bullet: "[実績ポイント3]"
      - bullet: "[専門分野・アプローチ]"
  
  - type: category_type
    number: "①"
    category_name: "[カテゴリ名]"
  
  - type: characteristics_challenges
    title: "[カテゴリ名] [タイプ名]：特徴と課題"
    sections:
      - section_title: "こんな人が当てはまる"
        items:
          - "[特徴1]"
          - "[特徴2]"
      - section_title: "改善のカギ"
        items:
          - "[改善ポイント1]"
          - "[改善ポイント2]"
      - section_title: "なぜ[問題]なのか？"
        explanation: "[問題の原因説明]"
        visual_elements:
          - "[視覚的な説明要素1]"
          - "[視覚的な説明要素2]"
  
  - type: improvement_plan
    title: "[カテゴリ名] [タイプ名]：改善プラン《[プラン名]》"
    proposal_message: "[提案方針のメッセージ]"
    daily_schedule:
      morning:
        goal: "[目標値]"
        description: "[説明]"
      lunch:
        goal: "[目標値]"
        description: "[説明]"
      dinner:
        goal: "[目標値]"
        description: "[説明]"
  
  - type: practice_example
    title: "[改善プラン名] 実践メニュー例 [食事タイミング]"
    menu_examples:
      - "[メニュー例1]"
      - "[メニュー例2]"
    success_tips: "[成功のコツ]"
  
  - type: empathy_question
    title: "[質問形式のタイトル]"
    content:
      - "[共感を促す内容1]"
      - "[共感を促す内容2]"
      - "[質問]"
  
  - type: value_proposition
    title: "私たちが大切にしていること"
    key_message: "[核心的なメッセージ]"
    goal_statement: "[ゴール設定に関する考え方]"
  
  - type: results
    title: "[期間]で[対象]がこれだけ変わった"
    metrics:
      - label: "[指標名]"
        value: "[数値]"
      - label: "[指標名]"
        value: "[数値]"
    highlights:
      - "[注目ポイント1]"
      - "[注目ポイント2]"
  
  - type: testimonials
    title: "参加者からの嬉しいお声"
    key_insight: "なぜ継続できたか"
    quotes:
      - "[参加者の声1]"
      - "[参加者の声2]"
  
  - type: cta
    title: "[行動喚起のタイトル]"
    content: "[問い合わせ方法など]"
```

## デザイン指針

- **背景**: シンプルで読みやすい背景色。パターンや装飾的なアイコンは最小限に
- **タイポグラフィ**: 見出しは大きく、本文は読みやすいサイズ
- **色使い**: テーマカラーを統一し、強調したい部分をアクセントカラーで
- **レイアウト**: 情報が整理され、視線が自然に流れる配置
- **視覚要素**: 必要に応じて図解やアイコンを使用（ただし装飾目的ではない）

## 使用時の注意事項

1. **コンテンツの内容に応じてスライドタイプを選択**
2. **不要な装飾（パターン、背景アイコンなど）は後から削除可能**
3. **タイトルやメッセージは簡潔で明確に**
4. **箇条書きは3-5項目を目安に**
5. **実績は具体的な数値で示す**

## テンプレート適用の流れ

1. 作成したい資料の内容（文章や要件）を提供
2. このYAMLテンプレートをもとに、内容に合わせたスライド構成を生成
3. NotebookLMでYAMLを指定してスライドを作成
4. 必要に応じて装飾を調整・削除

## Cursor（またはClaude）で使用する場合のプロンプト例

### 新しい資料を作成する場合

```
以下の内容でスライド資料を作成してください。
添付されている「notebooklm_yaml_prompt.md」のテンプレート構造をもとに、
以下の内容を反映したNotebookLM用のYAML形式のスライド指定を生成してください。

【作成したい資料の内容】
[ここに資料の内容、テーマ、伝えたいメッセージなどを記述]

【参考テンプレート】
notebooklm_yaml_prompt.md のスライドパターンと構造を使用

【出力形式】
- YAML形式のスライド構成
- 各スライドの内容を具体的に記述
- 不要な装飾（パターン、背景アイコンなど）は最小限に
```

### PDFから直接YAMLプロンプトを生成する場合

```
添付されているPDF資料を分析して、
NotebookLMでスライドを作成する際に使用するYAML形式のプロンプトを作成してください。

【要件】
1. PDFのスライド構造、レイアウト、デザインパターンを分析
2. 同様のスタイルで新しいスライドを作成する際に使えるYAMLテンプレートを作成
3. 各スライドタイプの定義と使用例を含める

【出力形式】
- YAMLスキーマ定義
- 各スライドタイプの説明
- 実際の使用例
- デザイン指針

【注意事項】
- パターンや背景の装飾的なアイコンは後から削除可能であることを考慮
- 実用的で汎用的なテンプレートとして設計
- 他の資料にも転用できる形式にする
```
