# NotebookLM用スライド作成YAMLプロンプト（営業資料版・20ページ程度）

## 使い方

このプロンプトを使用して、NotebookLMで20ページ程度の営業資料を作成する際に、以下のYAML形式でスライド構成を指定してください。

## 基本的なスライド構成パターン（営業資料用）

1. **タイトル・自己紹介スライド**（1-2枚）
   - 講師名・肩書き
   - 実績や信頼性を示すポイント（箇条書き3-4点）

2. **問題提起・共感スライド**（1-2枚）
   - 質問形式で読者の課題に共感
   - よくある失敗経験への共感

3. **価値提案スライド**（1枚）
   - 私たちが大切にしていること
   - 独自のアプローチ

4. **カテゴリ・タイプ分類スライド**（1-2枚）
   - タイプ番号＋名称（シンプル）

5. **特徴・課題説明スライド**（2-3枚）
   - タイトル：カテゴリ名＋特徴と課題
   - 「こんな人が当てはまる」セクション
   - 「改善のカギ」セクション
   - 「なぜ○○なのか？」セクション

6. **改善プラン・提案スライド**（2-3枚）
   - タイトル：カテゴリ名＋改善プラン名
   - 提案方針（メッセージ）
   - 具体的なプラン内容

7. **実践例スライド**（1-2枚）
   - 実践メニュー例
   - 成功のコツ

8. **実績・成果スライド**（2-3枚）
   - 数値で示す成果
   - 注目すべきポイント

9. **参加者の声スライド**（1-2枚）
   - なぜ継続できたか
   - 具体的な声

10. **CTA・問い合わせスライド**（1枚）
    - 行動喚起
    - 問い合わせ方法

**合計：約15-20スライド**

## NotebookLM用YAML指定例（営業資料用）

```yaml
slides:
  # タイトル・自己紹介
  - type: title_intro
    title: "[講師名・肩書き]"
    content:
      - bullet: "[実績ポイント1]"
      - bullet: "[実績ポイント2]"
      - bullet: "[実績ポイント3]"
      - bullet: "[専門分野・アプローチ]"
  
  # 問題提起・共感
  - type: empathy_question
    title: "[質問形式のタイトル]"
    content:
      - "[共感を促す内容1]"
      - "[共感を促す内容2]"
      - "[質問]"
  
  # 価値提案
  - type: value_proposition
    title: "私たちが大切にしていること"
    key_message: "[核心的なメッセージ]"
    goal_statement: "[ゴール設定に関する考え方]"
  
  # カテゴリ・タイプ分類
  - type: category_type
    number: "①"
    category_name: "[カテゴリ名]"
  
  # 特徴・課題説明
  - type: characteristics_challenges
    title: "[カテゴリ名] [タイプ名]：特徴と課題"
    sections:
      - section_title: "こんな人が当てはまる"
        items:
          - "[特徴1]"
          - "[特徴2]"
      - section_title: "改善のカギ"
        items:
          - "[改善ポイント1]"
          - "[改善ポイント2]"
      - section_title: "なぜ[問題]なのか？"
        explanation: "[問題の原因説明]"
  
  # 改善プラン
  - type: improvement_plan
    title: "[カテゴリ名] [タイプ名]：改善プラン《[プラン名]》"
    proposal_message: "[提案方針のメッセージ]"
    plan_details:
      - "[プラン詳細1]"
      - "[プラン詳細2]"
      - "[プラン詳細3]"
  
  # 実践例
  - type: practice_example
    title: "[改善プラン名] 実践例"
    examples:
      - "[例1]"
      - "[例2]"
    success_tips: "[成功のコツ]"
  
  # 実績・成果
  - type: results
    title: "[期間]で[対象]がこれだけ変わった"
    metrics:
      - label: "[指標名]"
        value: "[数値]"
      - label: "[指標名]"
        value: "[数値]"
    highlights:
      - "[注目ポイント1]"
  
  # 参加者の声
  - type: testimonials
    title: "参加者からの嬉しいお声"
    key_insight: "なぜ継続できたか"
    quotes:
      - "[参加者の声1]"
      - "[参加者の声2]"
  
  # CTA
  - type: cta
    title: "[行動喚起のタイトル]"
    content: "[問い合わせ方法など]"
```

## デザイン指針（営業資料用）

- **背景**: シンプルで読みやすい背景色。パターンや装飾的なアイコンは最小限に（後から削除可能）
- **タイポグラフィ**: 見出しは大きく、本文は読みやすいサイズ
- **色使い**: テーマカラーを統一し、強調したい部分をアクセントカラーで
- **レイアウト**: 情報が整理され、視線が自然に流れる配置
- **視覚要素**: 必要最小限の図解やアイコン（装飾目的ではない）
- **ページ数**: 約15-20ページを目安に

## 使用時の注意事項

1. **営業資料は簡潔に**: 1スライド1メッセージを心がける
2. **不要な装飾は削除**: パターン、背景アイコンなどは後から削除可能
3. **タイトルやメッセージは簡潔で明確に**
4. **箇条書きは3-5項目を目安に**
5. **実績は具体的な数値で示す**
6. **全体で15-20ページ程度に収める**

## テンプレート適用の流れ

1. 作成したい営業資料の内容（文章や要件）を提供
2. このYAMLテンプレートをもとに、内容に合わせたスライド構成を生成（約15-20スライド）
3. NotebookLMでYAMLを指定してスライドを作成
4. 必要に応じて装飾を調整・削除
