# 暫定版フォルダ

## 概要
確定版として公開する教材をバージョン管理するフォルダです。

## バージョン管理のルール

### フォルダ構成
```
暫定版/
├── v1/          # バージョン1（2025年2月2日リリース）
├── v2/          # バージョン2（将来のリリース）
└── README.md    # このファイル
```

### バージョンアップの手順

1. **新しいバージョンを作成**
   - `暫定版/v2/` などの新しいフォルダを作成
   - 確定版のファイルをコピー

2. **バージョン情報を記録**
   - 各バージョンフォルダ内の `README.md` にリリース日と内容を記載

3. **GitHub Pagesに公開**
   - `docs/` フォルダにコピーして公開
   - どのバージョンからコピーしたかを記録

## 現在のバージョン

- **v1**: 2025年2月2日リリース（第1章のみ）

## 注意事項

- 作業用ファイル（`教材HTML/`）は更新し続けます
- 確定版として公開するもののみ、このフォルダにバージョン管理してください
- 各バージョンは履歴として残しておきます
