第3章　コーチングコミュニケーションの前提

第1章・第2章でコーチングの価値とセッション全体像を掴んだら、次は「コーチとしてどのような心構えで対話に臨むのか」を明確にする番です。コーチングはテクニックの積み重ねではなく、在り方（Being）と姿勢によって支えられています。効果的なコーチングには、成果を生むコミュニケーションの"前提（プリサポジション）"が存在します。これらを理解・体得することで、コーチのOS（考え方の土台のようなもの）が整います。本章では、18の前提を４つの視点にグルーピングし、実践でどう活かすのかを具体的に解説していきます。

3-1 前提はコーチのOSである

コーチングの4層構造との対応

コーチングの実践は、「自己基盤（Being）→コーチングマインド→ラポール（信頼関係）→スキル（Doing）」という4層構造で成り立っています。コーチングコミュニケーションの前提は、土台の自己基盤・コーチングマインドを強化する役割を担います。

スキル（Doing）
ラポール
コーチングマインド
自己基盤（Being）
階層 意義 関連する前提
自己基盤（Being） 自分を整え、責任とリソース意識を保つ ⑨⑩⑪⑫⑰⑱

スキル（Doing） 行動レベルで適応し、成果を生む ⑦⑩⑬⑮

前提は「こうすべき」というルールではありません。「こう捉えると行動がうまく機能する」という信念の置き所です。セッションで迷った時に前提へ立ち返ると、コーチの内的状態が整います。そして、自然と適切な言葉や介入が選べるようになります。

II. ラポールを築く前提（①〜⑤）

発見

このセクションを学ぶ前に、以下の問いについて考えてみましょう。

  1. あなたが誰かと信頼関係を築けたと感じた瞬間は、どんな時でしたか？その時、どんなことが起こっていましたか？

  3. コーチングセッションで、クライアントが「安心して話せる」と感じるために、コーチはどんな姿勢や行動が重要だと思いますか？

解説

ラポールを築く前提とは

説明

クライアントと信頼関係（ラポール）を築き、安心して話ができる場を整えるための前提群です。ラポールは、コーチングセッションの基盤となる重要な要素です。ラポールが築かれていない状態では、クライアントは本音を話すことができず、セッションの効果も限定的になります。逆に、ラポールがしっかりと築かれている状態では、クライアントは安心して内面を探索し、深い気づきや行動変容につながります。

ラポールを築く前提は、コーチの在り方（Being）と姿勢に深く関わっています。テクニックだけでラポールを築くことはできません。コーチ自身が、クライアントを尊重し、理解しようとする姿勢を持つことが重要です。以下の5つの前提を理解し、実践することで、効果的なラポール構築が可能になります。

ラポールモードに必要な要素を4層構造に当てはめると、下図のようになります。各層は、下から上へと積み上げられ、それぞれが次の層を支える基盤となります。

① 自己基盤

コーチが自己開示をすることは、クライアントとの間にラポールを築くのに有効です。コーチ自身が自分の経験や感情を適切に共有することで、クライアントも安心して話せる環境が生まれます。

② コーチングマインド

コーチは100%クライアントの味方であり、最大の理解者・応援者となります。そのような姿勢により、クライアントとの間にラポールが築かれます。クライアントの可能性を信じ、共に目標達成を目指す姿勢が重要です。

③ 信頼関係

ラポールモードでは、クライアントとの間に信頼関係の基本を作ります。この信頼関係は、その後のセッション全体の基盤となり、クライアントが安心して内面を探索できる環境を提供します。

④ スキル（技術）

コーチは「認める」「聴く」スキルを駆使することにより、クライアントとの間にラポールを築きます。これらのスキルは、クライアントが自分の話を聞いてもらえていると感じ、安心感を得るために不可欠です。

① 相手の世界観を尊重する

説明

人はそれぞれ独自の「世界の見方（マップ）」を持っており、それ自体が尊重されるべきです。同じ出来事でも、人によって受け取り方や意味づけが異なります。コーチは、自分の価値観や見方を押し付けるのではなく、クライアントの世界観を理解し、尊重する姿勢を持つことが重要です。

コーチが「こうあるべき」と押し付けると、相手の表情が硬くなり、言葉が短くなります。これは、クライアントが「自分の世界観が否定されている」と感じているサインです。このような状態では、ラポールが崩れ、セッションの効果も低下します。

コーチのアクションとしては、好奇心と質問で世界観を探ることが重要です。「どうしてそう感じるのか？」を丁寧に聴き、クライアントの世界観を理解しようとする姿勢を示します。クライアントの世界観を理解することで、より適切な質問や介入が可能になります。

例

会話例：

クライアント：「上司との会議が苦手で…」

コーチ（NG例）：「会議は苦手なものではなく、コミュニケーションの場ですよ。積極的に参加すべきです。」

→ コーチの価値観を押し付けている。クライアントの世界観を尊重していない。

会話例（改善版）：

クライアント：「上司との会議が苦手で…」

コーチ：「"苦手"とはどんな感覚ですか？ 具体的な場面をもう少し教えてもらえますか？」

→ クライアントの世界観を理解しようとする姿勢を示している。好奇心を持って質問している。

注意すべきサイン
  • クライアントの表情が硬くなる
  • 言葉が短くなる、返答が表面的になる
  • 視線が合わなくなる、姿勢が後ろに傾く
  • 「でも」「でもね」という反論が増える

② 行動と変化はエコロジーで評価する

説明

行動の変化は本人だけでなく、家族・組織・社会にも波及します（エコロジー：周囲への影響を考慮すること）。コーチングでは、クライアント個人の変化だけでなく、その変化が周囲に与える影響も考慮することが重要です。エコロジーチェックを行わないと、変化が周囲と衝突して停滞し、本人が違和感を抱くことになります。

エコロジーチェックは、ゴール設定や行動計画の段階で行うことが効果的です。クライアントが設定したゴールや行動が、家族、チーム、組織、社会にどのような影響を与えるかを一緒に確認します。影響がネガティブな場合は、ゴールや行動を調整する必要があります。

コーチのアクションとしては、エコロジーチェックを行い、影響範囲を可視化することが重要です。影響範囲を可視化することで、クライアントは自分の行動が周囲に与える影響を理解し、より適切な判断ができるようになります。

[図] エコロジーチェックの影響範囲
クライアント
家族
配偶者・子ども・親
チーム・組織
同僚・上司・部下
社会・環境
コミュニティ・地球環境

クライアントの行動変化は、周囲の様々な領域に影響を与えます。エコロジーチェックでは、これらの影響を確認し、整合性を保つことが重要です。

例
  • 「この変化は、家族やチームにどんな影響を与えそうですか？」
  • 「長期的に見て、あなたらしさと一致していますか？」
  • 「このゴールを達成することで、周囲の人々はどのように感じると思いますか？」
  • 「この行動が、あなたの価値観と一致していますか？」
注意すべきサイン
  • 変化が周囲と衝突して停滞している
  • 本人が違和感を抱いている
  • 家族やチームからの反発がある
  • 長期的な価値観と一致していない

③ 抵抗はラポール不足のサイン

説明

反抗的なクライアントはいません。ラポール（信頼関係）が不足しているだけです。抵抗は、クライアントが「この場は安全ではない」「この人は理解してくれない」と感じているサインです。コーチは、抵抗をクライアントの問題として捉えるのではなく、自分の関わり方を見直す必要があります。

抵抗のサインとしては、質問に「わかりません」「別に…」と淡白に返す、話題を変えられる、視線が合わなくなる、姿勢が後ろに傾くなどがあります。これらのサインに気づいたら、コーチは自分の関わり方を振り返り、ラポールを再構築する必要があります。

コーチのアクションとしては、自分の関わり方を振り返り、感情を映し確認することが重要です。「今どんな気持ちですか？」と感情にアクセスし、クライアントの内面を理解しようとする姿勢を示します。また、前提①「相手の世界観を尊重する」を再確認し、クライアントの世界観を理解しようとすることも重要です。

例

会話例：

クライアント：「うーん、別に何も…」

コーチ：「さっきより声のトーンが落ちましたね。少し戸惑いがありますか？」

→ 非言語情報（声のトーン）に気づき、感情にアクセスしている。抵抗を責めるのではなく、理解しようとする姿勢を示している。

④ 行動と人格を分けて捉える

説明

行動には肯定的意図があり、人そのものを否定するものではありません。クライアントが「自分はダメだ」と自己否定に陥っている場合、コーチは行動と人格を分けて捉える必要があります。行動がうまくいかなかったからといって、その人がダメなわけではありません。

コーチのアクションとしては、肯定的意図を見つけ、「その意図を叶える別の手段」を一緒に探すことが重要です。行動の背後にある肯定的意図（例えば、「失敗を避けたい」「安全を保ちたい」など）を理解し、その意図を叶える別の方法を一緒に探します。

例

会話例：

「先延ばしすることにはどんな良い点がありましたか？ それを保ちながら他の方法はありますか？」

→ 行動（先延ばし）を否定するのではなく、その背後にある肯定的意図を探っている。人格を否定せず、行動の意図を理解しようとしている。

⑤ 人は持てるリソースで最善を尽くしている

説明

現時点のリソース（持っている力や資源）と状況の中で、本人は最善を尽くしています。クライアントが「もっと頑張るべきだった」「もっと早く行動すべきだった」と自責に陥っている場合、コーチは「ここまでどうやって乗り越えてきたか」を振り返り、リソース棚卸しを行うことが重要です。

他責や自責が強く、感情が尖っている場合、コーチはクライアントのリソースに光を当てる必要があります。過去の成功体験、持っているスキル、周囲のサポートなど、クライアントが持っているリソースを再確認することで、自己効力感を高めることができます。

例
  • 「これまでうまくいった時は、どんな力を使っていましたか？」
  • 「ここまでどうやって乗り越えてきましたか？」
  • 「あなたが持っている強みやリソースは何だと思いますか？」
  • 「周囲の人で、サポートしてくれそうな人は誰ですか？」

ラポール前提のチェックポイント

以下の項目を確認し、ラポール構築に必要な前提が実践できているかチェックしましょう。

  • ✓ 相手の世界観を信頼して聴けているか
  • ✓ 行動が周囲に与える影響を一緒に見渡せているか
  • ✓ 抵抗が起きた時、自分の関わりを見直しているか
  • ✓ 行動と人格を切り分けて会話できているか
  • ✓ クライアントのリソースに光を当てているか

3-3 観察と意味づけを磨く前提（⑥〜⑧）

コーチは"聞こえる言葉以上の情報"を受け取る専門家です。言葉の背後を読み取り、意味づけを柔らかく行うための前提が⑥〜⑧です。

前提⑥ 問題・制限はチャンスである

  • 意味：問題は大切な意図を教えてくれる「変化の入口」です。
  • サイン：同じ課題が繰り返し浮上します。
  • コーチのアクション：問題を掘り下げ「そこから何を学べるか？」と問い直します。
  • 会話例：「この課題が現れることで、どんな大切なものを守れているのでしょう？」

前提⑦ 行動をキャリブレートする

  • 意味：非言語情報（表情・姿勢・呼吸など）から相手の状態を読み取ります（キャリブレート：観察して調整すること）。
  • サイン：クライアントの変化に気づけず、質問が空回りします。
  • コーチのアクション：観察→仮説→確認の流れを徹底します。
  • ミニ演習：パートナーの話を聴きながら、変化をメモ→確認。「今の笑顔は何か閃きがありましたか？」

前提⑧ 地図（マップ）は領土（テリトリー）ではない

  • 意味：言葉は現実を表す地図にすぎず、事実そのものではありません。
  • サイン：「○○に違いない」と単一の解釈に固執しています。
  • コーチのアクション：メタ質問（質問についての質問）で意味づけをほぐします。
  • 質問例：「それは他にどんな見方ができますか？」「もし友人が同じ状況なら、あなたはどう声をかけますか？」

観察レンズのチェック

□ 問題を"成長への入口"として扱えているか

□ 非言語情報から状態変化を読み取れているか

□ 解釈を固定せずに、意味づけの幅を広げられているか

3-4 柔軟に介入する前提（⑨〜⑯）

ここでは行動面とプロセス設計に直結する前提を扱います。コーチ自身の柔軟性を高め、選択肢をデザインする視点がポイントです。

内面を整える（⑨⑩⑪⑫）

前提⑨：心を管理しているのは自分自身

  • 状態が乱れたとき、外部ではなく「自分がどう整えるか」に焦点を移します。
  • セッション前のルーティン（呼吸・姿勢・意図の確認）を持ちます。

前提⑩：心と身体は一つのシステム

  • 姿勢が変わると感情も変わります。感情がざわついたら身体から介入します。
  • 例：クライアントと一緒に深呼吸→思考がクリアになります。

前提⑪：人は必要なリソースを既に持っている

  • 過去の成功体験を掘り起こし、「できる自分」を再確認します。
  • リソースカード（得意・経験・支援者）を作成しておくのも有効です。

前提⑫：すべてのプロセスは全体性を広げる

  • 目の前の課題解決に留まらず、クライアントの人生全体で何が広がるかを見据えます。
  • 行動目標だけでなく、得られた学びにもフォーカスします。

柔軟に動き続ける（⑬⑭⑮⑯）

前提⑬：失敗はなくフィードバックがあるのみ

  • うまくいかなかった経験から学びを抽出します。「何が分かったか？次はどうするか？」

前提⑭：相手の反応がコミュニケーションの成果

  • 自分の意図より相手の受け取り方を重視します。反応を観察し、アプローチを微調整します。

前提⑮：最も柔軟な人がシステムをリードする

  • 固定観念に縛られず、新しい質問・視点を試します。コーチの柔軟性がセッション全体を牽引します。

前提⑯：プロセスは選択肢を広げるよう設計する

  • 行動案は一択ではなく複数提示します。「A案が難しかったら、B案・C案は？」と選択肢を用意します。

柔軟性セルフチェック

□ セッションの失敗から学びを言語化しているか

□ 相手の反応を成果指標として扱えているか

□ 質問・ワークのレパートリーを増やす努力をしているか

□ 行動計画に複数の選択肢を残せているか

3-5 未来へ力を向ける前提（⑰⑱）＋セルフルーティン

最後は、未来志向とエネルギーマネジメントを支える前提です。ここまでの前提を実践に落とし込むためのセルフルーティンを整えます。

前提⑰ 誰かにできるなら自分にもできる

  • 他者の成功は、自分にも可能性があるという証拠です。ロールモデルから戦略を学び、自分のリソースに翻訳します。

前提⑱ 意識が向いたところにエネルギーが流れる

  • ネガティブな点に意識を向けるほどエネルギーが奪われます。未来の可能性へ意識を向ける習慣を持ちます。

セルフコーチング・ルーティン（推奨）

  1. セッション前（30秒）：背筋を伸ばし深呼吸→今日の意図を一言で宣言→自身の強みを一つ思い出す。
  2. セッション後（2分）：感情・身体の状態を記録→得られたフィードバック→感謝を3つ書き出す。
  3. 週次レビュー（10分）：18前提のうち今週特に活用したもの／来週強化したいものをチェック。
  4. 学習計画：前提とスキルを結びつける書籍・動画・練習会をリスト化し、月に1つ試す。

  1. 録音を再生しながら、「問い→反応→次の問い」のリズムを書き出します。
  2. パターンA/B比較と同じ要領で、「命令口調になった瞬間」「問いで広がった瞬間」をマークします。
  3. 3つの視点（ラポール・観察・未来志向）でセルフフィードバックを記録します。

このセルフレビューを習慣化すると、3章で扱った18の前提が単なる知識ではなく、体で覚えた感覚（身体知）として定着していきます。
