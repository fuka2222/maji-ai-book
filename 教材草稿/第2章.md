# 第2章　基本的なコーチングの概要

この章では、コーチングの全体像と基本的な進め方を丁寧に紐解いていく。第1章で「なぜコーチングが人を動かすのか」を理解した今度は、「どのように進めるのか」「どんな意図で各ステップが構成されているのか」を学ぶステージだ。コーチとしてセッションを設計するとき、常に意図を持って進められるよう、各フェーズの役割と狙いを明確にしていこう。

---

## 2-1 コーチングセッションの全体像

### セッションはどのように構成されるのか

本教材では、セッションを「ラポールモード」「発見モード」「行動モード」「フォローアップ」という4つのモードで捉える。この構造は「5段階学習サイクル」（事例提示／自己発見／原理の理解／適用／決意）とも呼応しており、クライアントに安心を提供しながら気づきと行動を引き出す流れになっている。

1. **ラポールモード**：信頼関係の構築。クライアントが安心して話せる場のセットアップを行う。  
2. **発見モード**：質問と対話を通じて、テーマの全体像や深い思いを引き出す。  
3. **行動モード**：具体的な行動アイディアを設計し、コミットメントを引き出す。  
4. **フォローアップ**：セッション間の行動を振り返り、学びを定着させる。

この4つのモードが連続的に循環することで、クライアントは安心→気づき→行動→振り返りのサイクルを回し続けられる。コーチは各モードでどんな状態を目指すかを意識し、時間配分や質問の質を調整していく必要がある。

### 5段階学習サイクルとの対応

コーチングセッションを「学びの場」として捉えたとき、「5段階学習サイクル」という学習モデルとよく似た流れを辿る。このサイクルは以下のステップで構成される。

1. **事例提示**：具体的な事例やテーマを取り上げる。  
2. **自己発見**：テーマに関して自分の体験や感情を掘り下げる。  
3. **原理の理解**：そこから共通する原理や気づきを見出す。  
4. **適用**：原理を現実の行動に当てはめる。  
5. **決意**：やるべきことを決め、実行をコミットする。

コーチングセッションでも同じ順番が起こる。クライアントはまず具体的なテーマを持ち込み（事例提示）、対話の中で自分の内面を探索し（自己発見）、新しい気づきにたどり着く（原理の理解）。そしてその気づきをもとに行動を設計し（適用）、最後に「これをやる」と決意する（決意）。この5段階学習サイクルを意識すると、セッションが単なる会話ではなく、学びと変化のプロセスとして成り立っていることが理解しやすい。

### セッション設計のポイント

- **目的をクリアにする**：セッションの最初に、今回どんなテーマに取り組むのかを確認する。  
- **文脈を共有する**：クライアントが現在置かれている状況や感情の背景を聞き、セッションの文脈を整える。  
- **時間軸を意識する**：セッション内で過去・現在・未来を意図的に扱い、モード間の移行をスムーズにする。  
- **終わり方をデザインする**：セッションのクローズでは、学びの言語化と次の一歩を明確にする。  

### 講座での活用

講義40分でセッション全体像と5段階学習サイクルを解説し、20分のデモンストレーションで実際のモード切り替えを観察する。続く30分で受講生同士がロールプレイを行い、モードを意識しながらセッションを組み立てる練習をする。

## 2-2 ゴール設定の原理と実践

### ゴール設定がもたらすもの

コーチングの核となるのは、クライアントが心から望むゴールを明確にすることにある。ゴールは単なる目標ではなく、クライアントの価値観や人生の軸と深く結びついた未来像だ。未来を描くことで、前章で触れたコンフォートゾーンが未来側へ移動し、行動の起点が変化する。ゴール設定は、クライアントが「どんな未来を生きたいのか」を自覚し、その未来にふさわしい行動基準をセットする行為である。

### 研究が示すゴール設定の効果

目標設定研究の第一人者であるロックとレイサムは、具体的でチャレンジングなゴールがパフォーマンスを高めると示した。またゴルヴィッツァーの研究では、目標に対する「もし〜なら〜する」という実行意図（Implementation Intention）を明確にすると、実行率が向上することが分かっている。さらにマインドフルなメンタルコントラスト（現状の障壁を想定しながら未来を描くこと）は、現実的な行動計画を生み出すうえで効果的である。こうした心理学的知見は、コーチングにおけるゴール設定の重要性を科学的に裏付けている。

### 現状内ゴールと現状外ゴール

+ 現状内ゴール：今の延長線上で達成できる目標。達成可能性が高い一方で、自己肯定の範囲に留まり、大きな変化を生みにくい。  
+ 現状外ゴール：現状の延長では達成できない、未来の自分でなければ実現できない目標。前提条件や行動を抜本的に見直す必要がある。

コーチングでは、現状外ゴールを扱うことでクライアントのエフィカシーを引き上げ、突破的な変化を促す。現状外ゴールは非現実的な夢を語ることではなく、クライアントが本心から望む未来を「本気の目標」として扱うことがポイントだ。

### 認知科学コーチングの4ステップ

認知科学コーチングでは、現状外ゴールを設定し、認知を書き換えるために、以下の4ステップ（厳密には5ステップ）を踏む。

#### ステップ0：自己決定

そもそも今の自分の生き方を変えるの変えないのを決める段階である。今の自分の生き方が悪いわけではない（来年も今の仕事できるから）。その上昇曲線に自分の行きたいところがない場合、**生き方を変えることを決める**。ここで「もう変えるんだ」と決めたら、コーチングがスタートする。

#### ステップ1：自己理解

**自分が止められてもやってしまう自己欲求**を理解する。あなたのやってきた行動の中での**必殺技・価値パターン**を**自己能力**として出す。そして**自己機能**を決める。

重要なのは、意識で「僕がやりたいこと」を考えるのではなく、**像が何をしてきたか**を見ることである。あなたの像がすでにやってきてしまった行動をベースに見る。**無意識領域が本当に自分で認知しにくい**ため、コーチと共にやっていく必要がある。

#### ステップ2：ゴール設定

自己理解で出てきた**自己欲求**（像のパワー由来の今の生き方）を基に、あなたの今の生き方では**絶対行けないところにゴールを設定**する。コーチと一緒に**現状の外側のゴールを設定**する。自己欲求が来ることで**高いエフィカシーを得られる**。**コーチはエフィカシーを高める関わり**をする。

#### ステップ3：決断

**行きますかって決断しますか**というところである。これは**コーチの最も大事なところ**でもある。1人でコーチングできない理由、チャットGPTでできない理由がここにある。**行く時、やる時が1番怖い**のである。

ゴールを設定するところとか情報を集めることは簡単だが、その道に向かって**飛び出す**のが難しい。起業したい → 明日お金借りてこれますか、登記できますか、株式会社立てれますか。情報を集めてどうのこうのと言って2年3年経ってやらない。**脳みそが現状維持バイアスが働いてくれる**ため、ほとんどの人がやらない。

**コーチをつけている場合**、本当に行きたい方向に向かってやるには何かを変えるしかない。決断をすると、**脳みそは新しいカオス空間に出る**。今までいなかったところじゃないカオスに出ると、いろんなものをバランス取らなきゃいけない。そのカオス状態を**秩序的にコスモスを作ってくれる**（脳の機能がフル回転）。**飛び出るまでが大変**なので、飛び出るところまでを決断でやっていく。

#### ステップ4：アクション

実際に飛び出た後、そっちに**臨場感を感じ続けていないと像は動かない**。ちゃんとその臨場感をキープできているかどうかを**コーチと一緒に**やって、実際の行動を繰り返していく。ここまでやると**本当に人生変わる**。

#### 認知科学コーチングの本質

認知科学コーチングの本質は、**現状最適を選んじゃう**のが脳みそであることを理解し、**現状の自分の1番いいを選んじゃう無意識領域**を、**現状の外側のゴールを立てることによって再設定する**ことである。ゴールを立ててない人は**現状維持がゴールになっている**。それを現状の外のゴールに再設定することによって**認知をゴール側に変える**。**理想から見た意思決定に変える**ことが認知科学コーチングである。

### ゴールの質を高める質問

1. **何の制限もないとしたら、どんな未来を望むか？**  
   → 制約を取り払うことで、クライアントの本音が現れる。
2. **それを達成することで、どんな価値が手に入るか？**  
   → 価値観と結びつけることで、ゴールへの動機づけが高まる。
3. **誰と一緒にどんな景色を見ていたいか？**  
   → ゴールを社会的なインパクトと関連付ける。
4. **その未来の自分は、今と何が違うか？**  
   → コンフォートゾーンの移行を意識させる。

### ゴールの階層と時間軸

ゴールは一枚岩ではなく、時間軸や抽象度ごとに階層化されている。長期ビジョンと日々の行動を繋ぐために、以下のようなレイヤーを意識する。

| 時間軸 | 例 | 役割 |
|:---|:---|:---|
| 超長期（10年以上） | 人生のテーマ、社会的インパクト | 価値観・存在意義の確認 |
| 長期（3〜5年） | キャリア・事業の方向性 | 中期戦略の指針 |
| 中期（1年） | 1年後の実現状態 | 年間計画の立案 |
| 短期（1〜3ヶ月） | 具体的な成果指標 | プロジェクト単位の推進 |
| 超短期（1週間以内） | 行動タスク | 日常の習慣化 |

各層が整合しているかを確認し、上位ゴールが下位ゴールを牽引するように設計することが重要だ。

### 価値観とエコロジーチェック

ゴールは自分だけでなく、周囲・組織・社会への影響も含めて整合性を確認する。NLPでは、ゴールが自分の揺るぎない価値観と一致し、家族・チーム・社会・地球環境に対して良い影響を及ぼすかを検証するプロセスを「エコロジーチェック」と呼ぶ。コーチは次のような質問で確認を促す。

- このゴールは、あなたが大切にしている価値観と一致していますか？  
- ゴール達成が家族・関係者に与える影響はどのようなものですか？  
- ゴール達成後の生活リズムや健康状態はどう変わりますか？

エコロジーチェックを通じて、違和感や潜在的な抵抗をあらかじめ発見できる。

### モチベーションを保つ4つの問い

ゴールに向かう途中でモチベーションが落ちることは誰にでもある。以下の4つの問い（動画ノートで紹介されていたもの）を繰り返し問いかけることで、動機づけを再点火できる。

1. ゴールに到達すると、周囲の人にどんな良い影響を与えられますか？（できれば20個書き出す）  
2. ゴールを達成することで、あなた自身は何を得られますか？  
3. ゴールに向かう過程で、あなたはどのように成長するでしょうか？  
4. もしゴールを手放したら、どんな残念な未来が待っていますか？

これらの問いは、内的動機づけを強化し、困難な局面でも前進するエネルギーを生み出す。

### よくある落とし穴と対策

- **現状内ゴールに留まりがち**：安心感はあるが変化が起きない。→未来の自分の姿を詳細に描写し、現状外ゴールにアップデートする。  
- **他人の期待をゴールにしてしまう**：自分の価値観とズレが生じる。→価値観リストやライフドメインの棚卸しで自分軸に立ち戻る。  
- **達成手段がゴール化している**：手段が自己目的化する。→達成したい本質的価値や影響を再確認する。  
- **ゴールが多すぎて焦点がぼやける**：優先順位が不明瞭。→影響度と緊急度で分類し、1〜2本の最重要ゴールに絞る。

### ケーススタディ：若手リーダーのゴール設計

若手リーダーBさんは、当初「チーム売上を前年比120％にする」というゴールを掲げていたが、セッションを通じて「メンバー全員が自分の強みを活かし、挑戦できる環境をつくる」という本質的なゴールに行き着いた。  
超長期ゴールでは「挑戦を続ける人材のコミュニティを育てる」、長期ゴールでは「3年以内に挑戦文化を根付かせる」、中期ゴールでは「1年でメンバー全員が挑戦プロジェクトに着手」、短期ゴールでは「今月、1on1で挑戦テーマを引き出す」と階層化。さらに家族や上司への影響をエコロジーチェックし、モチベーションの4問いで自分の覚悟を固めた結果、現場の取り組みが加速した。

### 宣言の力

ゴールは言葉にした瞬間から現実への道筋が描かれ始める。コーチングでは、ゴールを宣言することを重要視する。宣言には「自分との約束を明確にする」「周囲からのサポートを受けやすくする」「行動の基準が高まる」などの効果がある。クライアントが自分の言葉でゴールを宣言するよう促し、必要があれば家族やチームに共有する仕組みを設計する。

### 演習：現状外ゴールを描く

1. 超長期〜超短期の各時間軸で、望む未来を自由記述する。  
2. ゴールが自分の価値観と一致しているか、関係者への影響がポジティブかをエコロジーチェックする。  
3. モチベーションを保つ4つの問いに答え、内的動機を言語化する。  
4. ゴールを一文で宣言し、実行意図（もし〜なら〜する）を添える。  
5. ペアで宣言を共有し、感じたこと・応援したいポイント・気づいたリスクをフィードバックし合う。

### 講座での活用

講義30分でゴール設定の理論と事例を解説し、20分のデモセッションでゴール設定のプロセスを観察する。演習40分では、受講生同士がゴール設定ワークに取り組み、宣言を行う。最後に10分かけて全体で気づきを共有し、ゴールが持つ力を体感する。

## 2-3 戦略とプランニング

### ゴールを実現するための「設計」

明確になったゴールに対し、どのような戦略とプランで臨むのかを設計するのがこのステップである。コーチはクライアントと対話しながら、アイデア出し、優先順位付け、行動計画の具体化をサポートする。ここでのポイントは、クライアント本人の言葉と意思でプランを組み立てること。コーチが答えを提示するのではなく、クライアントが自分の頭と感情を整理しながら「これでいく」と決められる状態をつくる。

### アイデアを広げる三つの問い

2章「コーチング実践テクニック」の動画でも紹介されていたように、アイデア出しには情報の拡張が不可欠だ。以下の問いを使う。

1. **絶対に手を抜いてはいけないことは何か？**（品質基準を明確にする）  
2. **やった方がいいのにやってこなかったことは何か？**（埋もれている可能性を掘り起こす）  
3. **想像してこなかったが面白そうなことは何か？**（常識の枠外からアイデアを出す）

これらを通じて、クライアントは既存の領域に留まらず、他分野からのヒントも取り入れながらアイデアを増やしていく。

### アイデアは知識の組み合わせである

アイデア出しでよくある誤解は、「天才的なひらめきが突然生まれるもの」という考え方だ。しかし実際には、アイデアは**既存の知識や情報の組み合わせ**から生まれる。現状の外側のゴールを達成するためには、自分たちの頭の外側の情報にアクセスする必要がある。

コーチングでは、クライアントが「アイデアが出ない」と感じている時、情報収集の視点を広げる質問を投げかける。情報を徹底して集めると、大抵の場合、ブレイクスルーにつながるアイデアの種が見つかる。

### 情報収集の3つの窓

ブレイクスルーにつながる価値ある情報（アイデアの種）は、以下の3つの窓から集めることができる。コーチは、クライアントがどの窓から情報を集められるかを問いかけ、情報収集のアクションを設計する。

#### ① 自社（社内）の情報

過去にうまくいった事例や、トッププレイヤーが何をしていたかという、失われがちな社内の事実データを掘り起こす。

**質問例**：
- 「過去に同じような状況でうまくいった事例はありますか？」
- 「社内で成果を出している人は、どんなアプローチを取っていますか？」
- 「以前は大切にしていたのに、今はやらなくなったことはありますか？」

**ポイント**：組織内には、共有されていない成功パターンや、時間とともに失われた有効な手法が眠っていることが多い。これらを再発見することで、新しいアイデアの種が見つかる。

#### ② 競合他社の情報

競合他社のトッププレイヤーが何をしているか、何をしてきたか、今後何をしようとしているかを調べる。

**質問例**：
- 「業界で成果を出している他社は、どんな取り組みをしていますか？」
- 「競合他社のトッププレイヤーは、どのような戦略を取っていますか？」
- 「業界のトレンドや、今後起こりそうな変化は何ですか？」

**ポイント**：同じ業界内の成功事例から学ぶことで、実現可能性の高いアイデアを抽出できる。

#### ③ 異業種の情報

全く異なる業種やカテゴリーから、共通する要素を抽出し、ビジネスモデルやアプローチのヒントを得る。

**質問例**：
- 「異業種で優れた成果を出している組織は、どんな仕組みを持っていますか？」
- 「全く違う業種から、参考になりそうな要素はありますか？」
- 「日常の中で見かけた、面白い仕組みやサービスはありますか？」

**ポイント**：異業種の優れた取り組みから、自分のビジネスに応用できる要素を見つける。異業種として区別せず、「これ入れたら吸収できる要素」という視点で観察することが重要。

### 情報収集をプランニングに活かす

情報収集の3つの窓を意識すると、アイデア出しが単なる「思いつき」から「体系的な探索」へと変わる。コーチは、クライアントがどの窓から情報を集めるかを明確にし、具体的な情報収集アクションを設計する。

**実践のポイント**：
- 情報収集は「次のセッションまでに調べてきてください」と依頼するだけでなく、その場で調べてもらうことも有効
- 集めた情報を「どう組み合わせるか」を問いかけることで、新しいアイデアを引き出す
- トッププレイヤーの情報を社内で共有できる仕組みを作ると、組織全体の成果が向上する可能性がある

### 数字付きアクションプラン

抽象的な「頑張る」「やる」という表現では行動に移りづらい。アクションプランは期日・質・量を数値化して具体的にする。

- ❌「運動を増やす」  
- ✅「2週間、毎朝7時に30分ランニングする」

数字を入れることで、進捗や達成度を測りやすくなり、行動が習慣として定着しやすくなる。

### システム思考で継続を設計する

行動が途切れる原因は、忘れる・時間がない・マインドが下がるなど様々だ。コーチングでは「忘れても続けられる仕組み」を整える。たとえば以下のような仕組みをクライアントと設計する。

| 課題 | 仕組み |
|:---|:---|
| 目標がぼやける | 毎朝デスクトップのゴールを確認する |
| やり方が分からなくなる | 毎週水・金の17時にメンターと振り返る |
| 進捗が見えない | 金曜18時にアクションレビュー会を実施 |

### マインドセットとストラテジー

行動は「マインド×ストラテジー」で決まる。どれだけ良いプランがあっても、マインドが足を引っ張れば行動は止まる。逆に、マインドが高くても戦術が曖昧なら成果には繋がらない。プランニングの場では、マインドセットを調整する質問（「何を信じ込めば加速できるか？」など）を交え、戦略と心の両方を整えていく。

### 演習：アクションプラン設計

1. ゴールに基づいて向こう1ヶ月のマイルストーンを設定する。  
2. 各マイルストーンに必要な行動を列挙し、優先度とリソースを整理する。  
3. 数字付きのアクションプランに落とし込み、日程表に組み込む。  
4. 障害が起こりそうなポイントを想定し、対策を仕組み化する（例：リマインダー設定、サポートネットワークの構築など）。

### 講座での活用

講義30分で戦略・プランニングの考え方を解説し、20分のケーススタディで実際のプランを分析する。演習40分では、受講生が自分のゴールに基づいたアクションプランを作成し、ペアでシェアしてフィードバックする。

## 2-4 コーチング前後の変化を捉える

### 前後の変化に着目する理由

コーチングは、セッションという瞬間的な体験だけでなく、その後の行動と結果があって初めて価値になる。クライアントの感情・認知・行動の変化を定点観測し、そこから学びを抽出して次の一手に繋げることで、セッションは連続した学習サイクルへと進化する。変化を見える化できないと、「何となく良かった」で終わってしまい、再現性が担保されない。

### 定性データと定量データを組み合わせる

変化を捉える際は、感情や気づきといった定性的情報と、数値で測れる定量情報の両方を扱う。定性データはクライアントの内面の質的変化を映し出し、定量データは進捗の速度や成果を客観的に示す。たとえば「自信が高まった（定性）」という報告を、「週次で実行できた行動数」「達成率」「上司からのフィードバック数（定量）」と組み合わせることで、変化の全体像が掴みやすくなる。

### セッションログと週次レポート

セッションごとのログに加え、クライアント自身に週次レポートを提出してもらうと、変化の微細な兆候を拾いやすい。推奨フォーマット例：

```
【目標】○○を△△までに達成する
【今週の達成度】予定した5アクションのうち4完了（80％）
【気づき】○○のときにエネルギーが下がる。朝にやると集中できる。
【次週の調整】朝8時までに最重要タスクを1件完了させる仕組みを導入
【サポートが欲しいこと】上司への報告タイミングについてコーチと相談したい
```

セッション前にこのレポートを読み込んでおけば、限られた時間の中で本質的な問いかけに集中できる。

### KPI・OKRとの連携

ビジネス系のテーマでは、コーチングで設定したゴールをKPIやOKRと紐づけておくと、現場の数字と対話が一致する。たとえば営業なら「商談数」「成約率」、マネジメントなら「1on1実施数」「メンバーの満足度スコア」、個人開発なら「制作時間」「アウトプット数」を指標化する。定量指標が決まると、変化が可視化され、クライアントの自己認識も精度が上がる。

### レビューのリズムを設計する

セッションごとの振り返りに加え、月次や四半期ごとにレビュー・ミーティングを設定して全体像を俯瞰する。レビューでは以下の流れを踏む：

1. **事実確認**：ログと指標を確認し、何が起きたかを整理  
2. **パターン分析**：成功・停滞それぞれの背景にあるパターンを抽出  
3. **学びの言語化**：次に活かせる原則や気づきを言葉にする  
4. **戦略の再設計**：今後の戦略・行動計画をアップデートする

このリズムを整えておくと、短期的なブレに振り回されず、長期的な成長軌道を描きやすい。

### ケーススタディ：プロジェクトリードの例

新規事業のプロジェクトリードを務めるクライアントAさんは、週次セッションで行動目標を設定し、毎回「提案準備時間」「社内調整件数」「自信スコア」を記録していた。最初の3週間は行動量が伸びず停滞したが、ログを分析すると「午後になると集中力が落ちる」「意思決定に時間がかかる」というパターンが浮かび上がった。そこで朝の時間帯に最重要タスクを終える仕組みを導入し、意思決定を阻む要因を整理する会議を設けたところ、4週目から行動量と自信スコアが急速に改善。クライアント自身も変化を体感でき、さらなる挑戦に踏み出す意欲が高まった。

### フォローアップとプラン修正

セッションの終わりには、次回までに実行するアクションと確認指標を明確にし、ログへ書き残す。次回冒頭でログを読み返しながら、「うまくいったこと」「止まったこと」「次に変えること」を整理し、必要に応じてプランを更新する。これを繰り返すことで、コーチングは常に最新の状況にフィットした実践となる。

### 演習：記録とレビューの実践

講座では模擬セッション後にログ記入とレビュー・ミーティングを実施し、定性・定量データの扱い方、問いかけの順序、プラン修正の手順を体験する。演習で使用するテンプレートとサンプルデータを用意し、どのように記録・分析・フィードバックを行うかを体感的に学ぶ。

### 講座での活用

講義30分で変化測定の考え方とツールを紹介し、30分のケーススタディで実際のログと指標を読み解く。演習40分では、受講生がペアでレビュー・ミーティングを実践し、最後の10分で全体共有とQ&Aを行う。実務に持ち帰れるテンプレートを配布し、受講後すぐに現場で運用できる状態を目指す。

## 章末まとめ

### 理解チェック

1. ラポールモード／発見モード／行動モード／フォローアップの役割を説明し、自分が得意なモード・今後磨きたいモードを記述する。  
2. 現状外ゴールを設定する際に注意したいポイントは何か。具体的な質問例を挙げて説明してみよう。  
3. アクションプランを行動し続けられる仕組みをつくるために、どんな要素が必要か。  
4. セッション前後の変化を観察することが、コーチングの効果測定にどのように役立つか。

### 課題

- 自分自身のテーマで、現状外ゴールとアクションプラン（数値化した行動計画）を作成し提出する。  
- セッション観察シートを使って、他の受講生のデモセッションを分析し、気づきをレポートにまとめる。  
- 次章の事前課題として、クライアントとの信頼関係がどのように構築されているか、自分の過去の経験から事例を持ち寄る。

### 次章へのブリッジ

セッションの全体像と基本的な進め方を理解したら、次はコーチとしてのマインドセットや在り方に焦点を当てる番だ。第3章では、NLPのコミュニケーション前提を通じて、コーチがどのような心構えで対話に臨むべきかを体系的に学ぶ。パーソナルな信念や価値観がセッションに与える影響を見つめながら、自己基盤を整えていこう。
